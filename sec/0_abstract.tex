\begin{abstract}
Subject-to-video generation renders a user-provided subject into a text-described video. Current systems are trained on paired reference--video data, which are scarce and, more importantly, biased: the reference is usually cropped from the target video, so a model is rewarded for pasting the reference into the frame rather than re-rendering the subject. We propose to learn appearance from image pairs only, where references deliberately differ from their targets in pose, scene and viewpoint, and to borrow motion entirely from a pretrained video diffusion transformer. Two mechanisms make static image supervision compatible with a video model. A Stage-I motion adapter turns the frozen backbone into a controllable motion carrier whose scale $M$ interpolates between a static regime, native motion and amplified motion; during Stage-II training the carrier runs in its static regime, so the image targets never ask the reference branch to suppress motion. The reference branch, which injects reference tokens into the backbone's self-attention, is read out as a paired difference between a real-reference pass and a learned null-reference pass, so only reference-dependent information reaches the prediction and the motion computation is never touched by the reference. At inference, motion, text adherence and reference adherence become three independent controls. Experiments on OpenS2V-Eval, including a copy-paste metric family validated on synthetic anchors, show that our image-trained model preserves subject appearance while copying the reference far less than video-trained baselines.
\end{abstract}
